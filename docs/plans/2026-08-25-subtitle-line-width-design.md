# 字幕单行长度设计

## 目标

在 Netflix 播放页控制台与选项页增加“单行长度”滑块，减少较长英文和中文被过早拆成多行的问题。

## 方案

- 在 `SubtitleAppearanceSettings` 中增加 `maxLineWidthPercent`，合法范围为 50–100，默认值为 96。
- 旧设置缺少该字段时迁移为 96，其余外观字段保持不变。
- 字幕 cue 使用 `width: max-content`，并以设置值和视口安全边距共同限制最大宽度。
- 播放页与选项页均提供实时滑块；修改沿用现有乐观渲染和后台自动保存链路。
- 不使用固定字符数或自动缩小字号，避免不同字体、字号和语言下产生不可预测的视觉变化。

## 验证

- 严格设置验证接受 50–100，拒绝越界值。
- 迁移测试确认旧设置获得 96，新值在 100 处正确夹紧。
- 字幕渲染测试确认 CSS 变量和最大内容宽度生效。
- 控制台测试确认滑块可访问名称、实时事件与设置更新结果。
