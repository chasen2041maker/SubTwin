# Netflix 页面控制台设计

## 目标

在保留 SubTwin 现有“官方中文字幕优先、外部翻译显式选择、失败恢复 Netflix 原生字幕”边界的前提下，把播放页体验升级为类似 Lingosive 的轻量常驻入口：页面只显示一个可拖拽的 SubTwin 悬浮按钮，点击后在隔离的 Shadow DOM 中展开控制台，并让所有字幕外观修改即时生效且持久化。

## 交互与状态

控制台默认折叠。悬浮按钮可拖动，但点击仍只负责展开；拖动位置按当前标签页保存在 `sessionStorage`，刷新和换集后继续使用，不进入扩展长期设置。控制台提供三个不同层级的动作：全局启用/关闭会写入现有扩展设置；“暂停当前页”只暂停当前 Netflix 标签页，不影响其他标签页或全局设置；关闭按钮只折叠控制台，始终保留可再次打开的悬浮入口。禁用或暂停必须立即清空 SubTwin 字幕并恢复 Netflix 原生字幕。

控制台直接提供中英文显示开关、上下顺序、两种语言的字体、字号、字重和颜色，以及阴影、行距、垂直位置和背景透明度。修改先乐观应用于当前字幕层，再通过后台持久化；后台推送仍是最终权威状态。控制台同时显示当前页面标题、播放/暂停状态、当前音轨、当前 Netflix 字幕轨、英文/简体中文目录可用性、官方中文字幕优先状态、翻译服务和运行错误。无法从 Netflix 页面安全读到的元数据明确显示“等待 Netflix 信息”，不伪造值。

## 架构

新增独立的 `PageControlSurface` React 边界和样式。它挂载在单独的 Shadow DOM host 中，host 本身不拦截播放器事件，只有按钮和面板开启 `pointer-events`。进入全屏时 host 移入全屏根节点，退出全屏时移回 `document.documentElement`；卸载时移除监听和 host。字幕 overlay 保持现有独立 Shadow DOM、非交互和故障恢复职责，控制台渲染失败不得影响字幕或 Netflix 播放。

content script 维护一个页面视图快照：运行设置、运行状态、目录摘要、标题、音轨、字幕轨和播放状态。Netflix 会话继续拥有字幕解析与调度；当前页暂停通过向会话传入一个 `enabled: false` 的临时运行设置实现。外观或全局开关更新使用新的、严格校验的 content-to-background 消息，后台读取私密设置、只替换公开字段并复用现有存储与广播通道，因此 DeepSeek Key 不进入页面控制台消息。

## 错误与安全边界

- 页面 UI 的存储、渲染、拖动或元数据探测失败均降级为不显示控制台，不得中断 Netflix。
- 外观保存失败时保留后台最终推送值，并在控制台显示保存失败状态。
- 页面消息只允许更新 `enabled` 和严格校验后的 `appearance`；provider、model 和 API Key 仍只能在受信任扩展页面中修改。
- 禁用、暂停、content script 失效、扩展重载或 host 被 Netflix 移除时，字幕层必须恢复原生字幕。
- 页面元数据只读取已渲染的可访问标签和 `document.title`，不读取 cookie、localStorage、认证头或 signed subtitle URL。

## 验证

自动化测试覆盖控制台渲染、可访问标签、全部外观控件、拖动边界、页面元数据清洗、消息严格校验、后台持久化、暂停/恢复和 Shadow DOM/fullscreen 生命周期。最终依次运行 `pnpm test`、`pnpm typecheck`、`pnpm build`、`pnpm zip`，再把生产构建加载到用户已登录的真实 Chrome，完成安装、播放、展开控制台、实时调节、快进、切轨、全屏、换集、刷新、暂停、禁用与恢复原生字幕的端到端记录。
